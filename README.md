## What is SciDraw AI?

SciDraw AI is an AI-powered platform that helps researchers, educators, and students create professional scientific illustrations without any design skills. Whether you need a molecular diagram, a cell biology figure, or a graphical abstract for your next paper, SciDraw AI generates publication-ready graphics in seconds.

> No more spending hours in Illustrator. No more hiring designers for a single figure.

## Key Features

### AI Image Generation

| Mode | Description |
|------|-------------|
| **Text to Image** | Describe what you need in plain text, get publication-ready illustrations instantly |
| **Sketch to Image** | Upload a rough sketch or doodle, AI transforms it into a polished figure |
| **Image Editing** | Multi-round conversation to iteratively refine your figures |

### Format Conversion & DPI Export

- Export to **PNG**, **PDF**, and **TIFF** with LZW compression
- Support for **300 / 600 / 1000 DPI** output
- AI super-resolution to keep images sharp at any size
- Meets the standards of **Nature**, **Science**, **Cell**, and all major publishers

### SVG Vector Conversion

- Convert any figure into fully editable **SVG** vector graphics
- Extract text layers for easy label editing
- Full vectorization to make every element adjustable
- Scale infinitely without quality loss
- Compatible with **Adobe Illustrator**, **Inkscape**, and **PowerPoint**

### Built-in Figure Checker

- Verify DPI at your actual layout width
- Check format compatibility with journal requirements
- Test grayscale readability for black & white print
- Simulate color-vision deficiency for accessibility
